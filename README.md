# Las Gallegos — Carta Digital

Sitio web estático de la carta digital de **Picantería Las Gallegos (Arequipa)** con pedidos directos por WhatsApp.

- **Web en producción (QR permanente):** https://las-gallegos.vercel.app

## Cómo actualizar platos, precios o promociones
1. Abre el archivo `menu-data.js` en este repositorio (puedes editarlo directamente desde GitHub en PC o celular).
2. Modifica `price` (usa `null` para mostrar `"Consultar"`), `available` (`true` o `false`) o agrega/edita productos y promociones.
3. Guarda los cambios (*Commit changes* en la rama `main`).
4. Vercel publicará automáticamente la actualización en `https://las-gallegos.vercel.app` sin cambiar tu código QR.
